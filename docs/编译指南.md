# 编译指南

程序 (引擎 + 手写的界面和内容) 不含任何原版资源, 编出来的安装包只有几十 MB。资源包另外用自己的原版生成, 见 [打包/资源包.md](打包/资源包.md)。

## 最省事: 用 GitHub Actions

1. Fork 本仓库 (或推到自己的仓库)。
2. Actions → **build** → *Run workflow*, 约 20 分钟后在该次运行页面底部的 Artifacts 下载各平台程序。
3. 想要发布页: 推送 `v` 开头的标签 (`git tag v1.0 && git push origin v1.0`), 会自动建 Release 并附上全部安装包。

| 产物 | 说明 |
|---|---|
| `SwordmanHD-win64.7z` | Windows x86_64 |
| `SwordmanHD-linux-x86_64.tar.xz` | Linux x86_64 |
| `SwordmanHD-macos.zip` | macOS (Intel + Apple 芯片通用), 未签名 |
| `SwordmanHD.apk` | Android arm64。仓库 Secrets 里配了 `ANDROID_KEYSTORE_BASE64` 等就用你的密钥签名, 没配用临时调试签名, 见 [打包/Android.md](打包/Android.md) |
| `SwordmanHD-unsigned.ipa` | iPhone / iPad, 未签名 (在 GitHub 的 macOS 机器上编), 见下面「苹果平台」 |
| `SwordmanHD-资源工具.zip` | 玩家用来生成资源包的工具 |

## 本机编译

### 准备

- Python 3.10+, 仓库根目录执行下面的命令。
- **Godot 4.7.2** (标准版) 放到 `tools/godot/godot` (Windows 为 `godot.exe`), 或用环境变量 `TDJ_GODOT` 指路径。Linux 上 `tools/ci_install_godot.sh` 可以自动装。
- 同版本**导出模板** (官方 `Godot_v4.7.2-stable_export_templates.tpz`, 约 1 GB): 解压其中的 `templates/` 到
  `~/.local/share/godot/export_templates/4.7.2.stable/` (Linux)、`%APPDATA%\Godot\export_templates\4.7.2.stable\` (Windows)、`~/Library/Application Support/Godot/export_templates/4.7.2.stable/` (macOS)。
  Linux 下 `GODOT_TEMPLATES=1 tools/ci_install_godot.sh` 一并装好。

### Windows / Linux / macOS 桌面版

三个桌面平台用同一个脚本, 在任何一种系统上都能出任何一种 (交叉导出):

```bash
python3 tools/build_windows.py --engine-only --zip           # Windows → dist/windows/SwordmanHD-win64.7z
python3 tools/build_windows.py --linux --engine-only --zip   # Linux   → dist/linux/SwordmanHD-linux-x86_64.tar.xz
python3 tools/build_windows.py --mac --engine-only --zip     # macOS   → dist/macos/SwordmanHD-macos.zip
```

- `--engine-only` 只出程序; 去掉它则连同已生成的资源包一起打 (自用完整包, 需要先生成资源)。`--edition=hd|classic` 只带一种画质。
- 包里有空的 `resource/`、`mod/` 文件夹 (各放一个说明文件) 和 `licenses/` (本项目与第三方许可文本)。
- 7z 打包需要 `7z`/`7zz` 命令, 没有会退回 zip; macOS 打包需要 `zip`/`unzip` 命令。
- 详情: [打包/Windows.md](打包/Windows.md)、[打包/Linux.md](打包/Linux.md)。

### Android

```bash
python3 tools/platform/setup_android.py                       # 第一次: 装 JDK 17 + Android SDK + 调试签名 (约 1~2 GB)
python3 tools/platform/build_android.py --no-packs            # dist/android/SwordmanHD.apk
```

详情: [打包/Android.md](打包/Android.md)。

## 苹果平台与签名

苹果的系统要求程序必须签名才能运行。本项目的程序都是**未签名**的, 由使用者自己签 (免费)。

### iPhone / iPad

- **云上用的 Xcode 版本**: `ios.yml` 跑在 GitHub 的 `xcode-27` 镜像 (macOS 27, preview) 上, 用 Xcode 27.1 (iPhone Duo 折叠屏的 SDK 从 27.1 起带); 版本写在该文件 `env.XCODE_VERSION`。镜像不稳或链接出错时, 退回 `runs-on: macos-15` + `Xcode_26*`。
- **编译**必须在 macOS 上用 Xcode。没有 Mac 就用 GitHub Actions 的 **iOS (unsigned IPA)** 工作流 (`.github/workflows/ios.yml`, 用 GitHub 的 Mac 机器编, 免费额度够用)。
  有 Mac: `python3 tools/platform/build_ios.py --ipa` 得到 `dist/ios/SwordmanHD-unsigned.ipa`; 或只导出 Xcode 工程 (任何系统, 不加 `--ipa`) 拿到 Mac 上用 Xcode 打开。
- **签名**用自己的 Apple ID: Sideloadly / AltStore, 或 Windows 上的 `tools/ios_win/install_ios.bat` 一键脚本。工程里的 Team ID 是占位值 `0000000000`, 签名工具会换成你自己的。
  - 免费 Apple ID: 证书 7 天, 到期重签; 同一账号同时最多 3 个自签 App。
  - 付费开发者账号 (99 美元/年): 证书一年, 也能用 TestFlight。
- iPad 与 iPhone 是同一个包, 没有单独的 iPad 版。玩家的安装步骤见 [安装与运行.md](安装与运行.md#iphone--ipad-自己签名安装), 工程细节见 [打包/iOS.md](打包/iOS.md)。

### macOS

- `--mac` 出的是未签名、未公证的通用 `.app`。使用者在自己的 Mac 上执行一次 `xattr -dr com.apple.quarantine SwordmanHD.app && codesign --force --deep -s - SwordmanHD.app` (去掉下载标记 + 本机临时签名) 就能运行, 步骤写在 [安装与运行.md](安装与运行.md#macos)。
- 想让别人双击就能开 (不用上面的命令), 需要付费开发者账号做 Developer ID 签名和公证。预设里签名与公证项默认关闭 (`game/export_presets.cfg` 的 `macOS` 预设, `codesign/*`、`notarization/*`), 填上自己的证书信息即可; 这一步本项目没有做过, 也没有验证。
- macOS 版没有在真机上验证过。
