# 安装与运行

面向玩家。先从 [Releases](https://github.com/zmnqaz/SwordmanHD/releases) 下载你平台的程序, 再用自己的原版游戏生成资源包 ([资源包.md](打包/资源包.md)), 放进程序旁边的 `resource/` 文件夹。
程序里**没有任何原版资源**, 缺资源包时游戏会在屏幕上写出该放到哪里。

资源包分两个文件夹: `resource/` 是必备的 (`common_*` 永远要放, 画质 `hd_*` 与 `classic_*` 二选一), `mod/` 是可选的 (如 `face_hk.pck` 港漫头像)。

## Windows

1. 下载 `SwordmanHD-win64.7z`, 解压 (Windows 11 可直接右键解压, 其他系统用 [7-Zip](https://www.7-zip.org/))。
2. 把 `.pck` 放进解压出来的 `resource` 文件夹 (`mod` 文件夹同理)。
3. 双击 `SwordmanHD.exe`。
4. 打不开或黑屏: 更新显卡驱动 (需要 OpenGL 3.3), 或在命令行运行 `SwordmanHD.exe --rendering-driver opengl3_angle`。`SwordmanHD.console.exe` 会显示日志窗口。

存档与设置在 `%APPDATA%\SwordmanHD\`。

## Linux

下载 `SwordmanHD-linux-x86_64.tar.xz`, `tar xf` 解压, 资源包放进 `resource/`, 运行 `./SwordmanHD.x86_64` (需要 OpenGL 3.3; 原生 Wayland 加 `--display-driver wayland`)。存档在 `~/.local/share/SwordmanHD/`。

## macOS

> macOS 版**没有在真机上验证过** (开发机没有 Mac, 只验证了能导出、是 Intel + Apple 芯片通用程序); 有问题请到 Issues 反馈。

1. 下载 `SwordmanHD-macos.zip` 并解压, 得到 `SwordmanHD.app`、`resource/`、`mod/` 三项, **保持它们在同一个文件夹里** (资源包放在 `.app` 旁边, 不要塞进 `.app` 里面)。
2. 程序没有 Apple 签名, 第一次要放行。在「终端」里进到该文件夹运行一次:
   ```bash
   xattr -dr com.apple.quarantine SwordmanHD.app && codesign --force --deep -s - SwordmanHD.app
   ```
   第一条去掉下载标记, 第二条给它一个本机签名 (Apple 芯片的 Mac 必须有签名才肯运行)。也可以右键 → 打开 → 仍要打开, 但 Apple 芯片上还是建议用上面的命令。
3. 双击 `SwordmanHD.app`。

存档在 `~/Library/Application Support/SwordmanHD/` (工程启用了自定义用户目录; 没有在 Mac 真机上核对过, 对不上时以游戏实际目录为准)。

## Android

1. 把 `SwordmanHD.apk` 传到手机安装 (允许「安装未知来源应用」), 打开一次后退出 (系统这时才会建资源目录)。
2. 把 `resource` 文件夹 (有 mod 就连 `mod`) 放进手机的 `Android/data/com.tdj.swordmanhd/files/` (**详细步骤、整包做法见 [手机安装与资源包.md](手机安装与资源包.md)**)。
   Android 11 起手机自带的文件管理器进不了这个文件夹, 用电脑: Windows 上把资源包放进 `C:\pck`, 手机开「USB 调试」连上电脑,
   双击资源工具里的 `tools\android_win\install_android.bat` (自动装 APK 并推资源包)。其他系统用 `adb push`, 见 [打包/Android.md](打包/Android.md)。

要求 arm64、Android 7.0 以上。

## iPhone / iPad (自己签名安装)

iOS 不能直接装网上下载的 App, 要用你自己的 **Apple ID** (免费的就行) 给 `SwordmanHD-unsigned.ipa` 签名后装上。

**一键脚本 (签名并装机; 资源包另用 `push_packs.bat` 推, 或用整包, 见 [手机安装与资源包.md](手机安装与资源包.md))**

1. 数据线把 iPhone/iPad 连到电脑, 手机上点「信任此电脑」。电脑需要 Apple 的设备驱动: 装 [iTunes](https://www.apple.com/itunes/) 或微软商店的「Apple 设备」(脚本发现没有会尝试自动安装)。
2. 把 `SwordmanHD-unsigned.ipa` 放进「下载」文件夹; 资源包 (`resource`、`mod`) 放进 `C:\pck`, 装好后用 `push_packs.bat` 推。
3. 双击资源工具里的 **`tools\ios_win\install_ios.bat`**。第一次会让你输入 Apple ID、密码和手机上收到的验证码 (只用于向 Apple 申请签名, 不保存密码)。
4. 等它显示安装完成, 再双击 `tools\ios_win\push_packs.bat` 把资源包推进应用 (或用「文件」App / Finder 拷, 或用自己编译的**整包** IPA 装完直接能玩)。

**不想用脚本**: 安装免费的 [Sideloadly](https://sideloadly.io/) → 连上手机 → 把 IPA 拖进窗口 → 填 Apple ID → Start。
装好后把资源包拷进 App: iTunes (Windows) / Finder (macOS) → 设备 →「文件共享」→ 天地劫, 或手机「文件」App → 我的 iPhone → 天地劫。

**第一次打开前, 在手机上** (iOS 16 及以上):
1. 设置 → 隐私与安全性 → **开发者模式** → 打开, 按提示重启 (这个开关第一次装完 App 后才出现)。
2. 设置 → 通用 → **VPN 与设备管理** → 点你的 Apple ID → 信任。
3. 打开「天地劫」。

**注意**: 免费 Apple ID 签的 App **7 天后会打不开**, 连上电脑再运行一次 `install_ios.bat` (或 Sideloadly) 重新签名即可, 存档不会丢。一个免费 Apple ID 同时最多装 3 个自签 App。付费开发者账号 (99 美元/年) 签名有效一年。
细节与原理见 [打包/iOS.md](打包/iOS.md)。

## 操作

键盘、鼠标、手柄、触屏都能玩, 按键见 [操作说明.md](操作说明.md)。设定 (F1) 里可改语言、画质、音量、分辨率、键盘和手柄按键, 也能一键整理行囊。
