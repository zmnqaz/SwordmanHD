# 操作说明

四种输入方式都能完整通关, 可以随时混用。

| 动作 | 键盘 | 手柄 | 鼠标 | 触屏 |
|---|---|---|---|---|
| 移动光标 / 选项 | ↑↓←→ 或 WASD | 十字键、左摇杆 | 指针移到哪选哪 | 虚拟十字键; 拖动卷动地图 |
| 确认 | Enter | A | 左键 | 点按; 右下大圆「确认」 |
| 取消 | Esc 或 C | B | 右键 | 双指点按; 「取消」键 |
| 查看单位 / 物品 | F | X | 中键 | 长按 |
| 装备效果预览 (营地、战场物品列表里选中装备时按住) | 空格 | R3 | | 长按 |
| 上 / 下翻页 | Q / E 或 PageUp / PageDown | LB / RB | 滚轮 | 左右快滑 |
| 游戏菜单 | 战场空地按确认、城镇按取消 (没有单独的菜单键) | Y | 点战场空地 | 长按战场空地 |
| 战场地图 | M | Back | | |
| 战场: 跳到下一个未行动的我方单位 | 取消键 (Esc / C) | B | 右键 | 双指点按 |
| 营地、商店: 左右栏切换 (如行囊 ↔ 角色) | Tab | LT | | 点另一栏 |
| 设定面板 (含整理行囊) | F1 (F10 同效) | Start | | 右上角绿色「设置」钮 |
| 加速档位菜单 | (设定里「游戏速度」) | (设定里「游戏速度」) | | 设置钮左边蓝色「加速」钮 (快进图标), 选 ×1.0 / 1.5 / 2.0 / 3.0 / 4.0 / 5.0 |
| 跳过对白 / 快进 | F3 / 按住 Ctrl | L3 / — | | |
| 攻略 | F2 (F4 同效) | Start → 设定 → 攻略 | | 设置钮 → 攻略 |

- **键盘改键**: 设定 (F1) →「控制器设置」→「键盘按键设置」, 逐个动作改键 (按一下想用的键即绑定, 可带 Shift)。改的是每个动作的**主键**, 备用键 (PageUp/PageDown、小键盘 + −、F4、F10 等) 保留; 方向键、Esc 固定。名字后带 `*` 是改过的, 带 `!` 是与别的功能共用了同一个键。
- **手柄**: 默认 A 确认、B 取消; 设定里有「交换」预设 (A/B 对调, 任天堂习惯), 也可以逐个动作改键。
- **触屏**: 只在手机/平板上启用 (电脑上用 `--touch` 参数可以拿鼠标模拟); 虚拟键可以用右上角「隐/显」收起来。
- **鼠标**: 指针悬停在选项上就会选中, 点已选中的项等于确认。
- 战场里光标按住方向键会连续移动 (和原版一样每 0.2 秒一格); 敌方回合不能操作。
