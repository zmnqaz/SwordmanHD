# 资源包 (.pck)

程序 (自己编的, 或 GitHub Actions 出的) 只含引擎和手写内容, **不含任何原作资源**。图像、声音、数据表等素材以 Godot 的 `.pck` 资源包形式放在程序旁边, 启动时由 `ResPacks` (`game/engine/core/res_packs.gd`) 挂载。
资源包由使用者用自己合法拥有的原作副本在本机生成, 属于对个人副本的演绎, **仅供个人使用, 不要上传或分享**; 生成它的工具不在本仓库。本文只说明资源包的布局和挂载规则, 供编译打包和做 mod 参考。

## 发布目录: `resource/` 与 `mod/`

```
SwordmanHD/
├── SwordmanHD.exe
├── resource/                  必备资源: 游戏离不开的; 画质 hd / classic 二选一, common 永远要放
│   ├── common_assets.pck      公用素材 (动画数据、像素画类贴图、音乐音效)
│   ├── common_story.pck       公用内容 (脚本、对白、数值、关卡、贴图分类表: 内容包 tdj)
│   ├── hd_images.pck          ┐ 高清画质: 放大后的头像 / 地图 / 大特效 / 界面大图 + 高清过场
│   ├── hd_movies.pck          ┘
│   ├── classic_images.pck     ┐ 原版画质: 1 倍原图 + 低分辨率过场
│   └── classic_movies.pck     ┘
└── mod/                       可选 mod: 叠加覆盖, 目录里所有 .pck 按文件名顺序挂在 resource/ 之后
    └── face_hk.pck            风格化对话头像 (素材 mod 的例子)
```

**resource 与 mod 的区别**: resource 里的包是游戏本体的素材, 缺了游戏不完整 (启动自检会提示); mod 是叠加在本体之上的可选内容, 有没有游戏都能玩, 后挂载的同路径文件覆盖先挂载的。做二次开发 (换素材、改内容) 的包放 mod 里即可。
旧版的平铺摆法 (包直接放 exe 旁) 仍然能读。`tools/build_windows.py --edition=hd|classic` 可以只带某一种画质的包 (hd 不带 `classic_*`, classic 不带 `hd_*`)。

包内路径 (`res://`) 的顶层前缀跟包的家族一致:

| 前缀 | 来自 |
|---|---|
| `res://common/` | `common_assets.pck` + `classic_images.pck` (后者补齐被高清替代的 1 倍原图, 路径与前者同一棵树) |
| `res://hd/` | `hd_images.pck` + `hd_movies.pck` |
| `res://classic/movies/` | `classic_movies.pck` |
| `res://mod/<包名>/` | `mod/` 里的包 |
| `res://content/tdj/` | `common_story.pck` |

过场视频逐段选: `hd_movies.pck` 里有这一段就播高清版, 没有就播 `classic_movies.pck`, 两个包都没装就跳过。没有 `hd_images.pck` 也没有 `classic_images.pck` 时启动会提示缺画面资源包。
人物与小贴图的 6 倍放大不靠资源包, 游戏运行时在显卡上实时生成 (见 [分辨率增强](../分辨率增强.md))。
这些包与平台无关: 同一份在 Windows / Linux / macOS / Android / iOS 上通用。

## 放到哪里

| 平台 | 位置 | 方法 |
|---|---|---|
| Windows / Linux | 可执行文件 (`SwordmanHD.exe` / `SwordmanHD.x86_64`) 同一目录 | 直接复制 `resource/`、`mod/` |
| macOS | **`.app` 旁边** (和 `SwordmanHD.app` 在同一个文件夹, 不要放进 `.app` 里) | 直接复制 |
| Android | `/sdcard/Android/data/com.tdj.swordmanhd/files/` | 先装一次 APK 并打开一次 (系统才会建这个目录), 再 `adb push`; 手机连在 Windows 电脑上时双击 `tools/android_win/install_android.bat` (包放 `C:\pck`) |
| iOS / iPadOS | 应用的「文件」文件夹 | 「文件」App → 我的 iPhone / iPad → 天地劫, 或电脑上 Finder / iTunes 文件共享; Windows 上双击 `tools/ios_win/push_packs.bat` (包放 `C:\pck`) |

缺包时游戏启动会在屏幕上提示它实际在找的目录。详见 [手机安装与资源包](../手机安装与资源包.md)。

## 做自己的素材 mod

素材 mod 就是一个 `.pck`: 里面的文件按相同的目录结构放好, 路径统一以 `res://mod/<包名>/` 开头, 放进 `mod/`。

清单文件每行 `源文件绝对路径<TAB>res://包内路径` (UTF-8); 文件原样打进去, 不导入、不转换:

```bash
# 按清单打成 .pck
godot --headless --script tools/release/pack_pck.gd -- --list=<清单> --out=<x.pck>
# 把 .pck 解回目录, 用来检查 (--path 要指向一个空工程目录)
godot --headless --path <空工程目录> --script tools/release/unpack_pck.gd -- --pck=<x.pck> --out=<目录>
```

同路径的文件, `mod/` 里后挂载的覆盖先挂载的, 所以只放你改过的文件就行; 包文件名按字典序决定挂载先后。
风格化对话头像 `face_hk.pck` 是一个例子: 装了它, 设定里才多出「头像风格」一行, 选中后对话头像改读这个包, 缺哪一张就退回默认头像; 命令行 `--face-style=classic|hk` 可临时指定。

## 整包 (资源打进安装包, 仅自用)

Android / iPhone / iPad 想「装完就能玩」, 可以把已有的资源包一起打进 APK / IPA, 见 [Android](Android.md)「整包」与 [iOS](iOS.md)「整包」。预制资源包放仓库根的 `pkgs/` (`pkgs/resource/`、`pkgs/mod/`, 整个目录被 `.gitignore` 忽略, 资源不入库)。
整包含对原作的衍生内容, 只能自己用, 不要公开发布。

## 自己出安装包

```bash
python3 tools/build_windows.py --engine-only --zip     # 只出引擎 (= GitHub Actions 出的包); 加 --linux / --mac 出另两个桌面平台
python3 tools/build_windows.py --packs-from=<目录>      # 带上该目录里现成的 resource/*.pck 与 mod/*.pck (默认读 dist/packs/)
python3 tools/build_windows.py --zip                   # 把 dist/packs/ 里已有的资源包一起放进发布目录
python3 tools/platform/build_android.py                # APK (先 python3 tools/platform/setup_android.py), 见 Android.md
python3 tools/platform/build_ios.py                    # Xcode 工程 / 有 Mac 时 --ipa, 见 iOS.md
```
