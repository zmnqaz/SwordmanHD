# 手机 / 平板安装与资源包

面向玩家。Android 手机、iPhone / iPad 上要玩, 需要**两样东西**:

1. **游戏程序** (APK 或 IPA): 只含引擎, 没有任何原作资源。
2. **资源包** (`.pck` 文件): 由你自己的原版游戏生成, 见 [资源包](打包/资源包.md)。

两样东西怎么凑到手机上, 有两种方法:

| | 方法一: 程序和资源分开装 (通用) | 方法二: 整包 (资源打进安装包, 仅自用) |
|---|---|---|
| 做法 | 装好程序, 再把资源包放进手机上指定的文件夹 | 自己编译时把资源包一起打进 APK / IPA, 装完直接能玩 |
| 谁能用 | 所有人 (下载 Releases 里的程序就行) | 自己编译的人 (需要电脑和预制资源包) |
| 优点 | 程序小 (几十 MB), 资源可以随时单独更新 | 一步到位, 不用拷资源 |
| 缺点 | 要拷资源 (下面写清楚怎么拷) | 安装包 GB 级, 装得慢; **含原作衍生资源, 只能自己用, 不能公开发布** |

## 资源包放到哪里 (一页看清)

**无论哪种平台, 资源包的文件夹结构都一样**: 一个 `resource/` 文件夹 (必备) 加一个可选的 `mod/` 文件夹。

```
resource/
  common_assets.pck      必放
  common_story.pck       必放
  hd_images.pck          ┐ 高清画质 (推荐), 或者
  hd_movies.pck          ┘
  classic_images.pck     ┐ 原版画质, 二选一
  classic_movies.pck     ┘
mod/
  face_hk.pck            可选: 港漫风格对话头像
```

| 平台 | 把 `resource/` 和 `mod/` 放到这里 |
|---|---|
| **Android** | 手机内部存储的 `/sdcard/Android/data/com.tdj.swordmanhd/files/` 下, 即 `…/files/resource/common_assets.pck` 这样 (也可写作 `/storage/emulated/0/Android/data/com.tdj.swordmanhd/files/`) |
| **iPhone / iPad** | 应用的「文件」文件夹: 手机「文件」App → 我的 iPhone (或我的 iPad) → **天地劫**; 电脑上 Finder (Mac) / iTunes (Windows) → 设备 → 文件共享 → 天地劫 |
| Windows / Linux | 程序旁边 (和 `SwordmanHD.exe` 同一个文件夹) |
| macOS | `SwordmanHD.app` **旁边**, 不要塞进 `.app` 里面 |

游戏找不到资源包时, 屏幕上会写出**它实际在找的目录**和里面有什么, 对照着放即可。

## Android

### 方法一: 程序和资源分开装

1. **装程序**: 把 `SwordmanHD.apk` 传到手机, 点开安装 (要允许「安装未知来源应用」)。需要 arm64、Android 7.0 以上。
2. **打开一次游戏再退出**: 这时系统才会建出资源目录 `…/Android/data/com.tdj.swordmanhd/files/`。(没有资源包时会看到「无法启动」的提示屏, 里面写着该放哪里, 这是正常的。)
3. **把资源放进去**, 三种方式任选:
   - **电脑 + Windows (最省事)**: 把资源包放进 `C:\pck` (里面是 `resource`、`mod` 两个文件夹), 手机开「USB 调试」用线连上电脑 (弹出授权点「允许」), 双击资源工具里的 `install_android.bat`: 自动装 APK 并把资源包推进手机; 手机上已有且大小一致的包会跳过。
   - **电脑 + adb (任何系统)**:
     ```
     adb shell mkdir -p /sdcard/Android/data/com.tdj.swordmanhd/files
     adb push resource /sdcard/Android/data/com.tdj.swordmanhd/files/
     adb push mod /sdcard/Android/data/com.tdj.swordmanhd/files/
     ```
   - **手机自带的文件管理器**: 只有 **Android 10 及以下**才进得去 `Android/data`。Android 11 起系统限制了, 用上面两种电脑方式。
4. 重新打开游戏。资源包大 (高清约 1.4 GB), 第一次读取会慢一点。

### 方法二: 整包 (自己编译, 仅自用)

在仓库根的 `pkgs/` 放预制资源包 (`pkgs/resource/*.pck`、`pkgs/mod/*.pck`, 整个目录被 git 忽略, 资源不入库), 然后:

```bash
python3 tools/platform/build_android.py --bundle                    # 高清画质, 约 1.3 GB
python3 tools/platform/build_android.py --bundle --edition classic  # 原版画质, 约 0.8 GB
```

得到 `dist/android/SwordmanHD-bundled-hd.apk`。手机上直接装它 (`adb install -r …` 或传到手机点开), **不用再拷资源**。用 `adb push` 往上面那个资源目录放同名的包, 还能单独更新其中某个包。
参数: `--pkgs <目录>` 换预制包目录, `--no-mod` 不带港漫头像, `--install` 编完直接装到连着的手机。
**整包含原作衍生资源, 只能自己用, 不要放到网盘、Releases 或任何公开的地方。** 原理与限制见 [打包/Android.md](打包/Android.md)「整包」。

**只有下载的 APK、没有源码, 想自己加资源?** 用 `bundle_apk.py` 给下载来的 `SwordmanHD.apk` 加上你的资源包, 它会用**你自己的密钥**重新签名:

```bash
python3 tools/platform/bundle_apk.py SwordmanHD.apk --pkgs <资源包目录>          # 资源包目录里是 resource/ 与 mod/; 加 --edition classic 出原版画质
```

- **为什么要重新签名**: 往 APK 里加了资源, 原来的签名就失效了; 没签名的 APK 手机会直接拒绝安装。Android 只检查「有没有签、签得对不对」, 不检查是谁签的, 所以**用你自己的密钥就行**, 不需要也拿不到项目的发布密钥。
- 第一次运行自动生成你的个人密钥 `~/.swordmanhd/bundle.keystore` (密码在同目录 `.pass`), 以后一直用它, 更新整包才能覆盖安装; **这个目录请自己备份**。
- 整包和 Releases 里的 APK **签名不同, 不能互相覆盖安装**: 手机上装着 Releases 的 APK 的话, 先卸载 (存档会丢, 先备份) 再装。
- 需要 JDK 17 + Android build-tools, 没有的话 `python3 tools/platform/setup_android.py` 一次性装好。详细参数和手动做法见 [打包/Android.md](打包/Android.md)「签名」。

## iPhone / iPad

iOS 不能直接装网上下载的 App: 要用你自己的 **Apple ID** (免费的就行) 给 `SwordmanHD-unsigned.ipa` **签名**后装上。

### 先装程序 (签名安装)

**Windows 一键脚本**: 数据线连好手机, 点「信任此电脑」; 把 `SwordmanHD-unsigned.ipa` 放进「下载」文件夹, 双击资源工具里的 `tools\ios_win\install_ios.bat`。第一次会让你输入 Apple ID、密码和手机上收到的验证码 (只用于向 Apple 申请签名, 不保存密码)。需要 Apple 的设备驱动 (装 iTunes 或微软商店的「Apple 设备」)。
**不想用脚本**: 装免费的 [Sideloadly](https://sideloadly.io/), 连上手机, 把 IPA 拖进窗口, 填 Apple ID, Start。

**第一次打开前, 在手机上** (iOS / iPadOS 16 及以上):
1. 设置 → 隐私与安全性 → **开发者模式** → 打开, 按提示重启 (这个开关装完 App 之后才出现)。
2. 设置 → 通用 → **VPN 与设备管理** → 点你的 Apple ID → 信任。
3. 打开「天地劫」。

**注意**: 免费 Apple ID 签的 App **7 天后会打不开**, 到期后连上电脑重新签名安装即可 (一个免费 Apple ID 同时最多装 3 个自签 App; 付费开发者账号 99 美元/年, 有效一年)。

### 方法一: 程序和资源分开装 (再放资源)

装好程序后, 把 `resource/`、`mod/` 放进应用的「文件」文件夹, 三种方式任选:

- **手机「文件」App**: 我的 iPhone (或我的 iPad) → **天地劫** → 把 `resource`、`mod` 文件夹拷进去 (资源包先传到手机, 比如 AirDrop / iCloud / 数据线)。
- **电脑 Mac**: Finder → 左侧点你的设备 → 「文件」→ 天地劫 → 把 `resource`、`mod` 文件夹拖进去。**电脑 Windows**: iTunes → 设备 → 文件共享 → 天地劫 → 添加文件夹。
- **Windows 一键推送 (不用 iTunes 拖)**: 包放 `C:\pck`, 双击 `tools\ios_win\push_packs.bat`。第一次会自动装一个独立的 Python 环境 (需要先装 Python 3.9+); 它把 `.pck` 推进应用。重装 IPA 后如果资源丢了, 再双击一次。

### 方法二: 整包 (自己编译, 仅自用)

给编好的未签名 IPA 加上预制资源包 (资源放仓库根的 `pkgs/`, 不入库):

```bash
python3 tools/platform/bundle_ipa.py dist/ios/SwordmanHD-unsigned.ipa                  # 高清画质, 约 1.4 GB
python3 tools/platform/bundle_ipa.py dist/ios/SwordmanHD-unsigned.ipa --edition classic # 原版画质, 约 0.8 GB
```

得到 `SwordmanHD-bundled-hd-unsigned.ipa`, 再用上面的方法**签名安装**, 装完直接能玩, **不用再拷资源**。IPA 本身要在 macOS (Xcode) 上编, 或推到 GitHub 用 Actions 的 `ios.yml` 编; 有了 IPA 之后这一步在任何系统上都能做。包大, 签名工具上传要等一会。
**整包含原作衍生资源, 只能自己用, 不要公开发布。** 细节见 [打包/iOS.md](打包/iOS.md)「整包」。

## 常见问题

**打开游戏只看到一屏「无法启动」的文字**
没找到资源包。文字里写着游戏**实际在找的目录**和里面有什么文件, 按上面的表把 `resource/` 放对地方 (里面要有 `common_assets.pck`)。Android 记得先打开一次游戏再放资源; 放好后重新打开应用。

**Android 文件管理器看不到 `Android/data`**
Android 11 起系统限制, 用电脑的 `install_android.bat` 或 `adb push`。

**iPhone / iPad 的「文件」App 里看不到「天地劫」**
要先装好、打开过一次游戏; 且必须是我们签名的这个版本 (它开了文件共享)。

**装上几天后打不开 (iOS)**
免费 Apple ID 的签名只有 7 天, 重新签名安装一次。

**画面还是像素风、头像不清楚**
`resource/` 里缺 `hd_images.pck` (高清头像 / 地图 / 特效) 或 `hd_movies.pck` (高清过场)。

**整包 APK / IPA 装不上或打不开**
包是 GB 级, 有的手机或安装器装不了; 这种情况改用方法一。整包没有在所有机型上验证过, 欢迎到 [Issues](https://github.com/zmnqaz/SwordmanHD/issues) 反馈机型和现象。
