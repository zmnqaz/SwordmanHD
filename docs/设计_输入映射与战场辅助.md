# 设计: F2 让位、手柄映射设置、隐藏宝箱开关、战场格子坐标、键盘改键

五项互相独立：F2 让位 (§1; 2026-10-25 起战场地图改默认 M, 见 §7)、手柄映射设置、隐藏宝箱显示开关、战场格子坐标、键盘改键 (§7)。键位总表。

## 1. F2 只留给战场地图

原版战场空闲光标态 F2 = 战场地图，所以设定面板不能再用 F2。

- (已被 §7 取代: 现在地图是可改键的动作 `map`, 默认 M；F2 默认是攻略。) `InputRouter` 里地图键只调栈顶 `ui_f2()`；非战场空闲态按它什么也不做（不吞，返回 false）。
- 设定面板热键现在是 **F1** (F10 同效，见 §7)；手柄用 Start（见 §2）。
- 调试覆盖层 `ui_debug_overlay.gd` 用 Ctrl+F9 / Ctrl+F10（只开发用），避免与设定热键冲突。

## 2. 手柄映射设置

### 2.1 逻辑动作与按键
可绑定的逻辑动作（手柄按键 → `UiAction`），方向键与左摇杆方向固定不可改：

| 动作 | 对应 UiAction / 信号 | 默认键 (标准) |
|---|---|---|
| confirm 确认 | CONFIRM | A (下键) |
| cancel 取消 | CANCEL | B (右键) |
| info 查看 | INFO (按下/松开) | X |
| menu 菜单 | MENU | Y |
| page_up / page_down 翻页 | PAGE_UP / PAGE_DOWN | LB / RB |
| switch 切换栏 | SWITCH (营地/商店双栏) | LT |
| select 装备效果预览 | SELECT / SELECT_UP (营地、战场物品列表按住 = 装备预览) | R3 (右摇杆按下) |
| map 战场地图 | 调栈顶 `ui_f2()` (同 F2) | Back/Select |
| settings 设定面板 | `settings_requested` (同 F10) | Start |
| skip_dialog 跳过对白开关 | `skip_dialog_toggled` (同 F3) | L3 (左摇杆按下) |

要点：
- **两个动作可以共用一个键** (用户自己绑的): 各界面只接收自己用得上的动作，栈顶不处理就继续往下传，不会串。存储用「动作 → 键」，路由时反查成「键 → 动作列表」。(原先 LT 同时绑 switch 与 target_prev、RT 绑 target_next; 2026-10-25 选目标跳转整个删掉了, 见 §7。)
- Back = 战场地图，Start = 设定，cancel 只有 B。
- **LT/RT 是轴不是按键**（`JOY_AXIS_TRIGGER_LEFT/RIGHT`）：按「轴值 ≥ 0.5 按下，≤ 0.3 松开」（迟滞）转成虚拟键（索引 = `JOY_BUTTON_MAX` + 轴号），与按键走同一套绑定。
- 摇杆与十字键方向不变；右摇杆暂不用。

### 2.2 预设
- **标准 (std，默认)**：如上表，A 确认 B 取消（Godot/Xbox 习惯）。
- **交换 (swap)**：A/B 对调（右键确认、下键取消），对应任天堂手柄习惯和原版重制版；其余同标准。
- **自定义 (custom)**：在预设基础上改过任意一键后自动变成「自定义」。

### 2.3 存储与校验
`settings.json`：
- `pad_preset`：`"std"` / `"swap"`（choice 行，进 `SettingsSchema.ROWS`）。
- `pad_map`：`{动作名: 按键索引}`，只存与当前预设不同的覆盖项（稀疏）；读回时 `sanitize`：未知动作名、非整数、超范围索引丢弃。缺失或旧版设定文件 → 全走预设。
- 「自定义」不单独存：`pad_map` 非空时面板上预设行显示「自定义」，切换预设行 = 清空 `pad_map` 并换预设。

### 2.4 界面
- 设定面板有一行「控制器设置 ▸」（确认键进入二级菜单，2026-10-29 起键盘 / 手柄设置都收在里面），二级菜单里有「手柄按键设置 ▸」和 `pad_preset` 预设行。
- 子面板 `PadMapPanel`（模态浮层，复用设定面板的版式与 `UiLayout` 表 `padmap.*`）：每行 = 动作名 + 当前键名；确认 = 进入「按下手柄键…」捕获状态，收到下一个 `InputEventJoypadButton`（或扳机过阈）即绑定；取消键/Esc/5 秒无输入 = 放弃捕获。底部「恢复预设」「完成」两个按钮，逻辑同设定面板（取消 = 还原进入前状态）。
- 键名按 Xbox 命名显示，检测到 PlayStation/Nintendo 手柄（`Input.get_joy_name`）时附加括注（如「A (✕)」）。
- 捕获期间 InputRouter 不把该键当游戏动作派发。

### 2.5 代码落点
- `engine/input/pad_map.gd`（`PadMap`）：纯数据逻辑，预设表、`resolve(preset, overrides) -> {键: [动作]}`、`sanitize`、键名；无节点依赖，可单测。
- `InputRouter`：手柄事件走 `_pad_press(button, pressed)`，查 `PadMap`；触发 map/settings/skip_dialog 三个非 UiAction 动作的分支；扳机轴转虚拟键。
- `Game.apply_settings` 里把设定同步给 `InputRouter.pad.set_config(...)`。

## 3. 隐藏宝箱显示开关

- 设定项 `show_hidden`（choice 0/1，默认 **0 = 与原版一致不显示**），只放设定面板。
- 范围：宝物类地图事件（`type > 0`，物品/金钱/事件宝物）且 `show == -1` 的；`type == 0` 的剧情事件不画。判定在 `BattleFlow.is_hidden_chest`。原版对 `show == -1` 不建图标。
- `refresh_hidden_treasures()` 按设定为这些事件建 / 删图标（单独记在 `_hidden_icons[e]`，与正常宝物分开管理）；拿走宝物时（`take_map_event`）一并释放。
- **显示**：原版宝箱图标只是一组很小的蓝白闪光，隐藏的用同一个图标看不出区别（半透明、染色、加框都试过，效果不好），所以隐藏宝箱用**同一套闪光动画的红色版**（`AnimPlayer.recolor_red`：普通部件走 `red_tint.gdshader`，发光部件走 `screen_blend.gdshader` 的 `red` 参数，蓝白换红，帧和节奏不变）。
- 生效时机：进战场时初始化一次；设定面板里改动后即时刷新（`Game.apply_settings` 末尾发 `settings_applied` 信号，战场流程订阅）；读档恢复（`resume`）后也按设定重建。
- 只影响显示，不改任何规则、随机数、存档；回归基线不受影响（默认关）。

## 4. 战场格子坐标

- 设定项 `coord`（0 关 / 1 开，默认关）。命令行 `--coord=0|1` 临时覆盖（截图用）。
- 光标所在格的「列,行」（从 0 起，与内部格坐标和 里的格坐标一致）显示成光标旁的小标签：贴在光标格上方，靠近画面顶时放到下方，横向夹在画面内，随光标移动。
- **只在玩家操作阶段显示**（`BattleScene.in_player_phase()`：我方回合、光标可操作、没有剧情/对白在跑、战斗没结束）；开场/过关剧情、敌方回合里不显示。
- `engine/battle/ui/battle_coord.gd`（`BattleCoord`）挂在战场界面层（与信息栏同层，晚于它加入，画在信息栏上面），标签带半透明底。标签位置 `tag_pos` 与显示条件 `shown` 是纯函数，单测直接测。只画不改规则，回归基线不受影响（默认关）。

### 4.1 隐藏宝箱提示

- 设定「隐藏宝箱显示」开着时，光标停在还没拿走的隐藏宝箱格（`BattleFlow.is_hidden_chest`）上，格旁显示「隐藏: <物品名>」：物品名走 Content 物品表（随语言），金钱类「金钱N两」，事件宝物「事件」。文案键 `battle.hidden_tip*`（ui.json）。
- 设定关时完全不显示（原版行为）；拿走后（`take_map_event` 删掉该事件）消失；显示时机同格子坐标（只在玩家操作阶段，触屏点格子移光标同样触发）。
- `engine/battle/ui/battle_hidden_tip.gd`（`BattleHiddenTip`）挂在战场界面层（BattleUi，坐标标签之后）；只读 `bs.st` 格子事件号与 `bs.ctl.flow.map_events`，不改战场流程。样式沿用 `BattleCoord` 常量；位置不开坐标时同坐标标签规则，同开时叠在坐标标签外侧一行（`tip_pos` 纯函数）。

## 7. 键盘改键 (2026-10-25)

起因: 玩家反馈默认键位不顺手: 战场地图应该是 M、选目标要有普通键 (原版只有小键盘 +/−, 笔记本没有)、键盘也要能改键。

### 7.1 默认键位 (与原版的差异)
| 动作 | 主键 | 备用键 (别名, 改键时保留) | 备注 |
|---|---|---|---|
| settings 设定面板 | **F1** | F10 (一直同效, 不能被别的动作占用) | 原版 F1 = 查看; 设定面板里还有「整理行囊」(原攻略面板里的按钮搬来的) |
| guide 攻略 | **F2** | F4 | 原版 F2 = 战场地图; 再按一次关闭 |
| map 战场地图 | **M** | — | 原版 F2 |
| switch 切换栏 | Tab | — | 营地/商店双栏 |
| confirm / cancel / info / page_up / page_down / select | Enter / Esc / F / Q / E / 空格 | 小键盘 Enter / C·返回键·Delete / — / PageUp / PageDown | 同改键前 (info 的 F1 别名让给了设定) |
| skip_dialog | F3 | — | 原来写死在 `_key` 里, 现在也可改 |

**没有键盘「游戏菜单」键** (2026-10-25 用户去掉): 战场空地确认 / 城镇取消本来就能开菜单, 再占一个键没用; 手柄 Y 和触屏「菜单」键仍走 `UiAction.MENU`。

固定不可改: 方向 (↑↓←→、WASD)、Esc (取消, 改键时也是「放弃」); F10 永远是设定的备用键 (回放锁里也要靠它), 不能绑给别的动作。按住 Ctrl = 快进对白, 不参与绑定。

### 7.2 实现
- `engine/input/key_map.gd` (`KeyMap`, 纯数据, 对称于 `PadMap`): `DEFAULTS` (动作 → [主键, 别名...])、`effective(overrides)` (覆盖项只换主键)、`resolve(overrides)` (键 → [动作], 同键多动作按 `ACTIONS` 顺序)、`lookup(table, event)` (先按「键 + Shift」查, 没有再按单独的键: 没绑 Shift+X 时 Shift+X = X, Ctrl+Enter 仍是确认)、`is_bindable`、`sanitize` (稀疏覆盖项)。键值是 Godot keycode, 可并入 `KEY_MASK_SHIFT`; Ctrl / Alt / Meta 不能绑。
- `InputRouter._key`: 方向键走固定表 `DIR_KEYS`; 其余键查 `_key_table` → 逐个动作 `_logic_action` (UiAction 类走界面栈, map / settings / skip_dialog / guide 直接处理, 键盘与手柄共用)。**同键多动作** (用户自己绑的: 同键的动作都触发), 各界面各取所需 (switch 只营地/商店接收, target_* 只战场选目标接收, 栈顶不处理就往下传, 与手柄 LT 同理)。`set_keys(overrides)` 由 `Game.apply_settings` 调, 改键即时生效。
- 设定: `key_map` (稀疏 `{动作: 键值}`, 不是行, 同 `pad_map`), 设定行 `key_edit` (动作行, 手机不列) 打开 `KeyMapPanel`。
- `engine/ui/key_map_panel.gd` (`KeyMapPanel`, 继承 `PadMapPanel`, 只换动作表/取值/捕获来源): 每个动作一行 (值 = 主键名, `*` 改过, `!` 与别的会同时生效的动作共用同一键); 确认 = 开始改键, 之后第一个可绑定键即绑定 (`InputRouter.key_capture`, 捕获中键盘除 Esc 外全部吞掉; 方向键 / F10 / 带 Ctrl·Alt 的组合不接受, 继续等); Esc 或 5 秒无输入放弃; 「恢复默认」「完成」; 取消还原进入前的覆盖项。同键的动作都会触发, 面板里带 `!` 提醒。
- 文案: `ui.json` 的 `key.*` / `settings.key_edit.*` (繁体由 `make_hant_text.py` 生成)。

### 7.3 炼化 / 行囊里的 Tab
营地「囊内乾坤」(行囊 ↔ 角色两栏) 里 Tab 一直是切栏 (`camp_item_window.gd` 的 `"tab"`), 没改。「诸物炼化」是先选第一件、再选第二件的两步流程, 没有左右两栏, 没有 Tab 动作。
